#### Prepare
Before you start with this lab make sure you have the basics down to get ready for the lab.
**AWS Command Line Interface (CLI)**
The AWS Command Line Interface (CLI) is a unified tool for managing your AWS services from the command line and in scripts. In this lab, you'll use the AWS CLI to interact with your Amazon Lightsail container deployments and services. To install the AWS CLI, follow the instructions here:

+ [Install AWS CLI](https://000011.awsstudygroup.com/en/1-cli-installation/)
+ [Basic CLI Setup](https://000011.awsstudygroup.com/en/2-basic-setup/)

**AWS Identity and Access Management - IAM**
IAM is a tool in AWS that allows you to securely control access to your AWS resources. You can use IAM to control authentication during login and authorization during resource usage.
+ [Manage access with IAM](https://000002.awsstudygroup.com/en/)

**Docker**
The Docker platform allows you to develop and run container applications. In this lab, you will use Docker to build and manage container images. These container images will be deployed to your Amazon Lightsail services.
